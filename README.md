# Курированный репозиторий зависимостей

Материалы к докладу {{TALK_TITLE}}. Дата: {{EVENT_DATE}}.

SCA отвечает на вопрос «что у нас есть». Гейт отвечает на вопрос «что можно взять». Это разные вопросы. Сканер не может запретить установку: он сообщает о найденном после того, как пакет уже попал в дерево зависимостей. Гейт срабатывает до резолвинга.

Здесь — инженерные заметки и конфиги для человека, который решил строить такое у себя. Ничего не нужно запрашивать: всё клонируется и читается сразу.

## Состояние слоёв

| Слой | Что лежит в репозитории | Состояние |
|---|---|---|
| 1. Зеркало | docker compose и конфиги Verdaccio | Рабочие материалы, дни |
| 2. Enforcement | Конфиги npm, pip, Poetry, uv, Maven, Gradle, egress и CI | Рабочие материалы, недели |
| 3. Каталог и политика | Схема каталога, критерии допуска, break-glass | Рабочие материалы, процесс навсегда |
| 4. Пересборка из исходников | Разбор, проверки, политика исключений | Разбор без решения. Готового решения у нас нет |
| 5. Бэкпорт патчей | Разбор стратегий версионирования и альтернатив | Разбор без решения. Готового решения у нас нет |
| 6. Свежесть | Что мерить и где подход ломается | Разбор без решения. Готового решения у нас нет |
| 7. MCP-слой | Модель угроз | Разбор без решения. Готового решения у нас нет |

Слои 4–7 объясняют асимметрию: построить дешевле, владеть дороже, и дорогое оказывается не там, где ждут. Стоимость указана только категориально.

## Быстрый старт

```
cd layer-1-mirror && docker compose up -d
```

Дальше — CHECKLIST.md, пункты 1–6. Проверка того, что получился именно гейт: tests/gate-smoke.sh.

Если у вас уже стоит Artifactory или Nexus: вам в пункт 7 CHECKLIST.md. Зеркало у вас есть, гейта, скорее всего, нет. Проверьте это, а не предполагайте.

## Границы

BOUNDARIES.md — список того, что этот подход не закрывает. Читайте его вместе с ARCHITECTURE.md: ни один слой не заменяет SCA, песочницу для postinstall и изоляцию рантайма.
