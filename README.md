# Nexaflow Supply Chain Gate

Этот репозиторий посвящен материалам, необходимым для построения курированного репозитория зависимостей.
Этот репозиторий работает как доверенный источник, а не как ещё один сканер.

Материалы к докладу "Вайбкодинг нельзя безопасность. Где ставить запятую?"

## Что здесь работает, а что нет
| Слой | Состояние |
|---|---|
| 1. Зеркало | Рабочие конфиги, поднимается за вечер |
| 2. Enforcement | Проверенные конфиги + список грабель |
| 3. Каталог и политика | Шаблоны, требуют адаптации под вашу организацию |
| 4. Пересборка из исходников | Разбор проблемы и trade-offs. Готового решения нет |
| 5. Бэкпорт патчей | Разбор стратегии версионирования. Готового решения нет |
| 6. Свежесть | Что мерить и где этот подход ломается |
| 7. MCP | Модель угроз, не реализация |

Слои 4–7 — причина, по которой это дорого владеть, а не дорого построить.

## Границы
BOUNDARIES.md.
Коротко: предложенный подход не закрывает следующий спектр проблем.
- 0-day внутри разрешённого пакета
- базовые образы контейнеров, сайдкары
- CI-экшены
- код, который агент пишет сам.
